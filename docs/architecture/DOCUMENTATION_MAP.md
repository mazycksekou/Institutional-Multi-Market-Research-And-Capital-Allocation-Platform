# Documentation Map

## Canonical Locations

| Documentation type | Canonical location |
| --- | --- |
| Architecture maps and system overviews | `docs/architecture/` |
| API docs and contract summaries | `docs/api/`, `docs/contracts/` |
| Setup and onboarding | `docs/setup/`, `docs/development/` |
| Operational docs and runbooks | `docs/operations/` |
| Inventories, audits, proofs, checkpoints | `docs/reports/` and subfolders |
| Historical and deprecated material | `docs/archive/` |

## Root Policy

- `README.md` is the only approved Markdown file at repository root.
- New Markdown should be written directly into the correct `docs/` destination.
- Historical evidence may remain archived when it is useful for audit or provenance.
