# Final Canonical Ownership

- `src.core` owns math/risk/pricing/execution primitives
- `src.data` owns historical data/line movement/source linkage
- `src.market_intelligence` owns market intelligence and signaling
- `src.backtesting` owns replay/simulation/dataset building
- `src.analytics` owns summaries/reporting/governance
- `src.research` owns experiments/calibration/feature control
- `src.services` owns orchestration and facades
- `src.security` owns safety/policy gates
- `src.brokerage` owns brokerage/execution boundaries
- `src.providers` owns provider registry/contracts
- `src.ai` owns disabled AI metadata only
