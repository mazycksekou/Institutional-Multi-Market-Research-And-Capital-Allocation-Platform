# Complete Streamlit Contract

## Dashboard contract surfaces

- operator instructions
- data source library
- historical import
- data quality check
- data explorer
- model projection
- paper bets
- backtest dashboard
- test one sport
- test all sports
- bankroll settings
- regression tactics
- system health

## Display layers discovered

| Layer | Examples |
|---|---|
| cards / metrics | rows tested, ready status, ROI %, win rate %, drawdown, missing link count |
| tables / dataframes | data quality, feature coverage, backtest summaries |
| charts | portfolio curves and volatility breakdowns |
| warnings / info | never-feature leakage guard, operator instructions |

## What the dashboard is for

It is a control surface for local decision support, not a live-trading or production-execution surface.
