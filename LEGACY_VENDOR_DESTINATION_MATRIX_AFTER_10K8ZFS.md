# LEGACY_VENDOR_DESTINATION_MATRIX_AFTER_10K8ZFS

## Executive Summary
This matrix maps the legacy vendor/provider/client/adapter surfaces to their future production destinations. It separates raw connector mechanics from normalized provider meaning, and it also shows where AI, brokerage, and scheduler-compatibility code should land.

## Method
- Reviewed the vendor audit, provider canonicalization plan, production-boundary scaffold, and the dependency/blocker maps.
- Grouped files by responsibility so families of thin wrappers are listed once instead of forcing repeated rows for nearly identical surfaces.
- Used the product-category boundary rule: connectors fetch raw data, providers normalize meaning, AI reasons under policy, brokerage executes only after safety gates.
